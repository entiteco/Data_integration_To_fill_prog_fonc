# Data Integration — Programmation fonctionnelle & MapReduce

Exercice de transformation de données de vols (JSON) et d'aéroports (CSV) en appliquant les principes de programmation fonctionnelle (`map`, `filter`, `reduce`) pour enrichir, agréger et analyser les passagers par vol et par ville.

## Stack technique
Python · Programmation fonctionnelle (map / reduce / functools) · JSON · CSV
